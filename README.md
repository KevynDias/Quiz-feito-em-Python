# 💻 Quiz de TI em Python

Projeto de estudo desenvolvido em Python: um quiz no terminal com 5 perguntas de múltipla escolha sobre conceitos básicos de TI, como hardware, redes e comandos do Windows.

## 📋 Funcionalidades

- Pede o nome do jogador
- Faz 5 perguntas de múltipla escolha (a, b ou c)
- Dá **2 tentativas** por pergunta
- Aceita respostas em maiúscula ou minúscula
- Mostra a pontuação atual a cada acerto
- Exibe uma mensagem final de acordo com o desempenho

## 🧠 Conceitos praticados

- Entrada de dados com `input()`
- Estruturas condicionais: `if`, `elif`, `else`
- Laço de repetição `for` com `range()`
- Controle de fluxo com `break`
- Tratamento de texto com `.lower()`
- Contador de pontos com variáveis
- Formatação de texto com f-strings

## ▶️ Como executar

1. Instale o [Python 3](https://www.python.org/downloads/)
2. Baixe o arquivo `quiz.py`
3. No terminal, execute:

```bash
python quiz.py
```

## 🏆 Pontuação final

| Pontos | Mensagem |
|--------|----------|
| 0 | Boa sorte na próxima |
| 1 a 3 | Você está em processo de aprendizado, parabéns |
| 4 a 5 | Parabéns, você demonstra domínio no assunto |
